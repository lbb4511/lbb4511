# 《小镇喧嚣》

**作者：** 吴毅　**初版：** 2007

## 关于本书

以湖北省某乡镇为田野，用"深描"笔法记录基层政权日常运作的喧嚣图景：税费征收、土地流转、村庄选举、上访与维稳。书中"播、闹、缠、磨"等概念，生动呈现了官民之间、上下级之间的利益博弈与话术较量。

## 核心概念

- **喧嚣的治理**：基层运作充满"搭台与拆台"的表演性。
- **政策变通**：正式制度与地方实际之间的反复拉扯。
- **利益互动**：乡镇政府、村干部与农民的三角博弈。

## 在藏书中的位置

与《苍黄》的小说视角、《叫魂》的历史视角形成互补，是观察中国基层制度如何"实际运转"的田野样本。
