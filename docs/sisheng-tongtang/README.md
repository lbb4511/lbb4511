# 《四世同堂》

**作者：** 老舍　**写作：** 1944—1948

## 关于本书

老舍最重要的长篇小说之一，写北平小羊圈胡同祁家四代人在抗战八年中的命运。从北平沦陷到抗战胜利，祁老人、瑞宣、瑞丰、瑞全及街坊邻居——钱默吟、冠晓荷、大赤包、小福子等——各自在亡国之痛中作出不同选择，展现中国人的屈辱、苟安与觉醒。全书分《惶惑》《偷生》《饥荒》三部，共一百回。

## 故事结构

- **第一部·惶惑**（第 1—34 幕）：北平陷落，祁家三代人在"忠"与"孝"、忍与抗之间动摇惶惑。
- **第二部·偷生**（第 35—67 幕）：日伪统治下的北平，偷生者（冠晓荷、大赤包）得势，守节者（钱默吟）觉醒反抗。
- **第三部·饥荒**（第 68—100 幕）：战争末期的饥饿与死亡，祁老人八十大寿与瑞宣的最终抉择。

## 在藏书中的位置

与《苍黄》《白鹿原》同属中国命运叙事的家族长卷，从市民文化视角补全抗战时期北平的生存图景。属"制度实践"板块。

> 注：老舍（1899—1966）作品已进入公有领域（作者逝世五十年），本库收录全文。
