# 《活着》

**作者：** 余华　**初版：** 1993

## 关于本书

地主少爷福贵嗜赌败家，此后接连经历内战、土改、大饥荒与亲人相继离世，最终与一头老牛相依为命。余华以近乎冷静的笔触书写平民的承受与韧性："人是为活着本身而活着的，而不是为了活着之外的任何事物而活着。"

## 核心命题

- **被动承受**：个体在时代洪流中被裹挟，无可选择。
- **活着的尊严**：在丧失一切之后仍保有生存的意志。
- **悲悯的叙事**：以最朴素的语言抵达最深的情感。

## 在藏书中的位置

作为"精神底色"的平民维度，与《野草》的精英式抵抗、《古拉格群岛》的极端挣扎形成对照——另一种不被吞噬的生存方式。
