# 《乡土中国》

**作者：** 费孝通　**初版：** 1948

## 关于本书

费孝通在抗战后期乡村社会调查基础上写成的十四篇讲稿，提炼出"差序格局""礼治秩序""熟人社会""无讼"等概念，刻画中国传统乡土社会的结构原理。这是一本理解中国基层何以如此运转的人类学入门书。

## 核心概念

- **差序格局**：以自我为中心、像石子投入水面的同心圆式人际关系网络，与西方"团体格局"相对。
- **礼治秩序**：依靠传统与教化而非法律维持的社会秩序。
- **长老统治**：教化权力在乡土社会的支配形式。

## 在藏书中的位置

与《血酬定律》同属"时间纵深"，从人类学维度补全中国制度的底层结构；其"差序格局"至今仍是观察基层权力网络的常用透镜。
