# 《万历十五年》

**作者：** 黄仁宇　**初版：** 1982（英文版）／1997（中文版）

## 关于本书

选择 1587 年（明万历十五年）这个表面平淡的年份，透过万历皇帝、张居正、申时行、海瑞、戚继光、李贽六个人物的命运，揭示明代以道德代替法律、以人事淹没技术的制度困境。黄仁宇以"大历史观"追问：一个庞大帝国为何"以道德代法制"而走向僵化。

## 核心命题

- **技术无法制度化的帝国**：税收、军事、财政缺乏数目字管理。
- **道德治国的悖论**：以"礼仪"与"伦理"整饬一切，反而纵容了阳奉阴违。
- **制度的失语**：个人在体系中的挣扎终被体系吞没。

## 在藏书中的位置

作为"制度文本"的反例，展示制度文本与实践之间的巨大断裂，是进入中国制度分析的最佳入口之一。
