# 《古拉格群岛》

**作者：** 亚历山大·索尔仁尼琴　**初版：** 1973

## 关于本书

以目击者与幸存者证词为基础，系统揭露苏联劳改营体系的完整图景：从第一次逮捕、审讯、监禁、流放，到极地森林、矿井与冻土上的强制劳动。索尔仁尼琴将这套体制称为"群岛"，散落于大陆各处，却由同一套极权逻辑维系。

## 核心命题

- **体制的暴力**：逮捕与审判如何成为国家机器的常态。
- **个体的内在自由**：在制度暴力极限中，人仍保有精神与尊严的选择。
- **证词即反抗**：以数十万人的经历为历史作证。

## 在藏书中的位置

补足"精神底色"的极端横截面——当制度暴力逼近极限，内在自由如何成为最后的抵抗。
