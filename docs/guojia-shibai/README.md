# 《国家为什么会失败》

**作者：** 达龙·阿西莫格鲁、詹姆斯·A. 罗宾逊　**初版：** 2012

## 关于本书

提出"汲取性"与"包容性"制度框架，解释国家兴衰的根源：汲取性政治与汲取性经济制度将权力与财富集中到少数精英手中，扼杀创新与增长；包容性制度则让民众分享政治与经济参与，驱动持续繁荣。全书以诺加利斯、韩国与朝鲜等对照案例展开论证。

## 核心概念

- **汲取性制度**：精英垄断权力与资源，榨取多数人。
- **包容性制度**：广泛参与、产权保护与激励相容。
- **制度是路径的根源**：地理与文化只是次要变量。

## 在藏书中的位置

提供"制度变迁"一轴的理论框架，与《变革中国》《大转型》的案例与历史分析互补。
