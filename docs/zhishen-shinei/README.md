# 《置身事内》

**作者：** 兰小欢　**初版：** 2021

## 关于本书

以地方政府投融资为主线，讲清楚中国政府如何在经济发展中"置身事内"：土地财政、城投平台、产业引导基金、债务与风险，从微观机制讲到宏观现象，是理解当代中国经济的现实读本。

## 主线内容

- **分税制改革**：中央地方财权事权划分如何重塑地方行为。
- **土地财政与城市化**：土地出让金成为地方政府运转的核心收入。
- **债务与风险**：地方债务扩张的机制及其对宏观政策的约束。

## 在藏书中的位置

与《转型中的地方政府》《经济学的思维方式》共同构成"经济基础"一轴，从政府行为视角解释中国增长奇迹的制度密码。
