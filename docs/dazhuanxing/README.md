# 《大转型》

**作者：** 卡尔·波兰尼（Karl Polanyi）　**初版：** 1944

## 关于本书

论证市场社会并非自然产物，而是19世纪以来人为建构的结果。当劳动、土地、货币被当作可以自由买卖的"虚拟商品"，市场的自我调节逻辑会撕裂社会；而社会必然以"反向运动"（保护性立法、工会、福利国家）进行抵抗。双向运动构成现代政治经济史的骨架。

## 核心概念

- **虚拟商品**：劳动、土地与货币并非真正的商品，却被迫进入市场。
- **市场嵌入社会**：市场化程度有其社会承受的上限。
- **双向运动**：市场扩张与社会自我保护互为攻守。

## 在藏书中的位置

为"制度变迁"提供第三种视角——市场并非自发秩序的宠儿，而是政治力量的产物，与《变革中国》《国家为什么会失败》形成张力。
