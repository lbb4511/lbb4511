# 《拥抱战败》

**作者：** 约翰·W. 道尔（John W. Dower）　**初版：** 1999

## 关于本书

讲述日本在1945年战败投降后，如何在美军占领下经历制度与精神的彻底重塑：从天皇制存废、宪法第九条到土地改革与官僚体系改造。道尔以大量细节呈现"败者"如何消化战败的屈辱，并将占领者的民主理想与日本本土传统相互嫁接。

## 核心命题

- **被占领的改造**：外部力量如何重塑一国的政治框架。
- **天皇制的转义**：战争责任被集中到少数人身上以保全国体。
- **反向输出**：占领时期的制度遗产如何影响战后日本。

## 在藏书中的位置

作为东亚近邻在关键转折点的镜像对照，与《论美国的民主》《枪炮、病菌与钢铁》共同构成"横向比较"一轴。
