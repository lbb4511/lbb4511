# 说疑

凡治之大者，非谓其赏罚之当也。赏无功之人，罚不辜之民，非所谓明也。赏有功，罚有罪，而不失其人，方在于人者也，非能生功止过者也。至治之国，有赏罚而无喜怒，故圣人极有刑法，而死无螫毒。故奸人服于刑，而愚人忍于生也。夫至治之世，其说在于忠信之臣，必断于法，而治之至也。

古之人君者，其忠臣之事君也，务在尽忠竭诚，不阿其私。故曰：忠臣之事君也，必以正道，不以谄谀。谄谀之臣，悦君之欲，而害君之事；忠信之臣，逆君之欲，而利君之事。故曰：明主之察其臣也，贵其直而不贵其谀，贵其忠而不贵其佞，则国治而身安矣。

昔者吴王阖闾杀其父而不报，则非仁也；楚庄王听谗而杀其臣，则非明也。故曰：凡为明主，务在审其听而明其断，则谗言之不能蔽，而忠言之不能阻矣。故曰：听谗而杀忠者，亡国之端也；任忠而拒谗者，治国之本也。此说疑之要旨也。

且夫疑其臣而任之，则臣不尽其忠；信其臣而任之，则臣尽尽其力。故曰：明主之任其臣也，必审其忠邪而后信之，信之则任之，任之则责之，责之则赏罚之。如此，则臣莫敢不忠，而国无不治矣。
