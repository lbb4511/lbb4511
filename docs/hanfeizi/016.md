# 三守

人主有三守。三守完，则国安身荣；三守不完，则国危身殆。何谓三守？一曰：亲爱臣，而勿听其言，恐其蔽主也。二曰：爱人，而勿用之，恐其专权也。三曰：恐人主之心，不可见也。

何谓三守之完？曰：人主有二问，二患，不可以不察也。曰：亲爱臣而骄之，则位不尊；爱人而专用之，则权不固。此其所以危也。故曰：明主之道，亲爱臣而不听其言，是以臣莫敢蔽主；爱人而不专用，是以臣莫敢专权。

人主有三患：一曰见疑，二曰夺柄，三曰壅塞。见疑，则奸臣之所为也；夺柄，则大臣之所以欺也；壅塞，则左右之所以蔽也。故曰：明主之治也，务在察此三者。察之则国治，不察则国乱。

明主之道，使人主之言不烦于耳，使人主之虑不困于内，则左右莫敢壅蔽，而奸臣莫敢擅断。故曰：人主之守，在于三守之完也。三守完，则人主之事无不通，而其国无不治矣。
