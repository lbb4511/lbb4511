# 难四

卫孙文子聘于鲁，公登亦登。叔孙穆子趋进曰："诸侯之会，寡君未尝后卫君也。今子不后寡君一等，寡君未知所过也。子其少安。"孙子无辞，亦无悛容。穆子曰："孙子必亡。为臣而君，过而不悛，亡之本也。"或曰：天子失道，诸侯伐之，故有汤武；诸侯失道，大夫伐之，故有齐晋。臣而君，过而不悛，亡之本也，是其子也。且孙子为臣而君，其法也；而叔孙以为过，则失其所以为君者矣。故曰：孙之亡，非以其为臣而君也，以其失礼而无悛也。

鲁阳虎欲去三桓，不克而奔齐。齐景公纳之。鲍文子谏曰："不可。阳虎有宠于季氏，而将杀季孙，以不利鲁国，而容其主也。今君若受之，是宠其利主也。"景公乃执之。或曰：鲍文子之言，恶阳虎之利也。夫阳虎之奔齐，为其负鲁国也。齐之受之，非利也。故曰：受之非，而执之是，此之谓审于利害之当。

齐景公之晋，与平公饮酒，晏子侍。师旷侍于平公。酒酣，平公曰："吾子与景公，夫何为者？"晏子对曰："臣闻之，晋之政，将归三家矣。"平公曰："何以知之？"对曰："臣见其君，虽听言而不行其令，虽用贤而不任其事，此所以将亡也。今君之治，亦然。"平公不悦。或曰：晏子之对，君人之失也。夫听言而不行，用贤而不任，此亡国之道也。而平公不以晏子之言为戒，而反不悦，此其所以失国者也。故曰：明主之治，务在听言而行之，任贤而用之，则国治而身安矣。

郑子产晨出，过东匠之闾，闻妇人之哭，抚其御之手而听之。有间，遣吏执而问之，则手绞其夫者也。异日，其御问曰："夫子何以知之？"子产曰："其声惧。凡人于其亲爱也，始病而忧，临死而惧，已死而哀。今哭已死，不哀而惧，是以知其有奸也。"或曰：子产之听，亦审矣。然其以声察奸，非其至也。夫察奸者，在审其情而参验之，不以一端而决也。故曰：明主之察奸也，务在参伍以验之，则奸情无不得矣。此难四之要旨也。
