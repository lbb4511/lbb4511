# 南面

人主之过，在已任臣矣，又必反其所为。故曰：使臣得尽其力，则主不失其所任。人主之所患，在信其臣而任之，任之而不得其力，则国乱。故曰：明主之任臣也，度其力而授之任，察其行而信之，故无妄任之患。人主之治也，务在于审其臣之能，而任之以当。任当则治，任不当则乱。故曰：任人之道，在明于当否，而不在于众寡也。

人主欲见其臣之贤不肖，则必审其听。听之而不当，则臣得乘其失而进其邪。故曰：听言之道，必参伍以验之，反覆以察之，则群臣之情得矣。人主之察也，不可不审也。

明主之道，不恃人之不我欺也，恃吾不可欺也；不恃人之不我窃也，恃吾不可窃也。故曰：明主使其臣，不能欺，不能窃，不能卖，此之谓信其法。

人主之患，在蔽于其臣。蔽者，之所以失其国也。故曰：明主者，不蔽于内，不制于外，此之谓全。全者，所以保其国也。故人主之务，在于察其臣之忠邪，而明于赏罚，则国治而身安。
