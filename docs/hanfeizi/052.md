# 人主

人主之所以身危国亡者，大臣太贵，左右太威也。所谓贵者，无法而擅行，操国柄而便私者也。所谓威者，擅权势而轻重者也。此二者，不可不察也。夫马之所以能任重引车致远道者，以筋力也；万乘之主、千乘之君所以制天下而征诸侯者，以其威势也。威势者，人主之筋力也。今大臣得威，左右擅势，是人主失力；人主失力而能有国者，千无一人。虎豹之所以能胜人执百兽者，以其爪牙也。当使虎豹失其爪牙，则人制之矣。今势重者，人主之爪牙也。君人者而失其爪牙，则虎豹之类也。

明主之治也，务在审其法而操其柄，不以假人，则大臣不敢擅权，左右不敢蔽主。故曰：人主之患，在于大臣太贵，左右太威，而不知察之也。夫大臣之贵也，必以其能媚于上而得之；左右之威也，必以其能欺于上而成之。媚上者，悦君之欲而导之非；欺上者，蔽君之明而售其私。明主不悦谄谀之言，不信近习之私，则大臣无所施其媚，左右无所施其欺矣。故曰：明主之治，务在塞其私门而固其公门，则国治而身安矣。故曰：君人者，以道制势，以法御臣，则大臣贵而不敢擅，左右威而不敢专，此所以身安而国保者也。
