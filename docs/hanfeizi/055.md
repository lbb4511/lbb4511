# 制分

夫凡国博君尊者，未尝非法重而可以至乎令行禁止于天下者也。是以君人者分爵制禄，则法必严以重之。夫国治则民安，事乱则邦危。法重者得情，禁轻者失实。故曰：制分者，务在明其所分，而审其所当。夫明主之畜臣也，务在审其功罪而制其禄赏，定其名分而不使之越。名分定，则臣不敢僭；赏罚明，则臣不敢欺。故曰：名分者，治之大纪也；制分者，明主之所以驭臣者也。

夫刑者，所以御之也；赏者，所以劝之也。刑赏者，国之二柄也，不可以偏废也。偏于赏，则臣骄而君弱；偏于刑，则臣惧而君孤。故曰：明主之治，务在刑赏并施，而参验以明，则臣莫敢不效其力，而国无不治矣。故曰：明主不近人情，不徇私意，而一切断之以法，则制分之术尽矣。故曰：分定则国治，分失则国乱，此制分之要旨也。
