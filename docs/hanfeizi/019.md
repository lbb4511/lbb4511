# 饰邪

凿龟数筴，兆曰大吉，而以攻燕者，赵也。凿龟数筴，兆曰大吉，而以攻赵者，燕也。剧辛之事燕，无功而社稷危；邹衍之事燕，无功而国道绝。赵代先得意于燕，后得意于齐，国乱节高，自以为与秦提衡，非赵龟神而燕龟欺也。赵又尝凿龟数筴而北伐燕，将劫燕以逆秦，兆曰大吉，始攻大梁而秦出上党矣，兵至釐而六城拔矣；至城阳而秦拔鄴矣，兵抵漳水而魏氏至矣。夫六城之拔，非赵龟神而燕龟欺也，赵又尝凿龟数筴而北伐燕，劫燕以逆秦，兆曰大吉，始攻大梁而秦出上党矣，兵至釐而六城拔矣，至城阳而秦拔鄴矣，兵抵漳水而魏氏至矣，邯郸危，则赵卒不信龟筴矣。故曰：龟筴鬼神，不足举胜；左右背乡，不足以专战。然而恃之，愚莫大焉。

古者先王尽力于亲民，加事于明法。彼法明，则忠臣劝罚必，则奸臣止。忠劝邪止而地广主尊者，秦是也；群臣朋党比周以隐正道，行私曲而地削主卑者，山东是也。乱弱者亡，人恃之者孤，而曰"吾存者""吾安者"，外不可恃也。昔者吴子胥以死事吴王，吴王信其谋而用之，破楚以强。及吴王死，夫差用子胥之言而灭越，后不用子胥之言，而亡其国。故曰：恃术而不恃信，恃势而不恃诈。苟恃其术与势，则虽无子胥之信，而国强；苟恃其信，则虽贤者而国亡。故曰：用道者，务在明法而审其势，则国家可治而主身可安矣。

且夫为政者，务在审于得失。夫赏罚者，人主之利器也。赏罚当，则国治；赏罚不当，则国乱。故曰：明主之治，务在审赏罚，明是非，然后可以安国而王天下矣。夫释法术而心治，尧不能正一国；去规矩而妄意度，奚仲不能成一轮；废尺寸而差短长，王尔不能半中。使中主守法术，拙匠守规矩尺寸，则万不失矣。君人者，能去贤巧之所不能，守中拙之所万不失，则人力尽而功名立。
