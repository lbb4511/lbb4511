# 存韩

韩事秦三十余年，出则为扞蔽，入则为席荐。秦特出锐师取地而韩随之，怨悬于天下，功归于强秦。且夫韩入贡职，与郡县无异也。今日臣窃闻贵臣之计，举兵将伐韩。夫赵氏聚士卒，养从徒，欲赘天下之兵，明秦不弱则诸侯必灭宗庙，欲西面行其意，非一日之计也。今释赵之患，而攘内臣之韩，则天下明赵氏之计矣。

夫韩，小国也，而以应天下四击，主辱臣苦，上下相与同忧久矣。修守备，戒强敌，有蓄积，筑城池以守固。今伐韩，未可一年而灭，拔一城而退，则权轻于天下，天下摧我兵矣。韩叛，则魏应之，赵据齐以为援，如此，则以韩魏资赵假齐以固其从，而以与争强，赵之福而秦之祸也。夫进击赵取宜阳，言扼韩之要也；进击魏，则韩与魏连衡。故攻赵而韩氏破，则赵危；攻韩而赵氏破，则韩危。臣窃以为秦宜救韩，以为自固之道，非伐韩也。

夫韩氏不畔，则秦不失一郡国之利，而韩为扞蔽，以安社稷，以为天下后。故曰：秦不宜伐韩，宜救韩以为名，而使韩事秦，则韩必以德事秦。韩之与秦，所谓唇齿之国也。秦伐韩而赵魏乘之，则秦必不利。故曰：舍韩之害而救之，此秦之福也。

臣斯昧死见，愿陛下幸察。夫秦齐之交，天下之枢也。齐事秦，则天下皆事秦矣；齐叛秦，则天下皆叛秦矣。今臣闻齐之叛秦，其谋在赵魏。赵魏之叛秦，其谋在韩。故臣愿陛下图韩以制赵魏，则齐不叛而天下定矣。
