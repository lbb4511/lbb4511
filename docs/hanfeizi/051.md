# 忠孝

天下皆以孝悌忠顺之道为是也，而莫知察孝悌忠顺之道而审行之，是以天下乱。皆以尧舜之道为是而法之，是以有弑君，有曲于父。尧舜汤武，或反君臣之义，乱后世之教者也。尧为人君而君其臣，舜为人臣而臣其君，汤武为人臣而弑其主，刑其尸，而天下誉之，此天下所以至今不治者也。夫所谓明君者，能畜其臣者也；所谓贤臣者，能明法辟、治官职以戴其君者也。今尧自以为明而不能以畜舜，舜自以为贤而不能以戴尧，汤武自以为义而弑其君长，此明君且常与当贤臣相去也，而世人不察，反以为美，此政之所以乱也。

故忠臣之于君也，务在尽其力而效其忠，不夺其君之柄，不慢其君之令。孝子之于亲也，务在顺其亲之志而养其亲之身，不逆其亲之教。悌弟之于兄也，务在敬其兄而安其家。此三者，治家治国之常道也。今世之所谓孝悌忠顺者，或以慈惠而乱政，或以曲从而害义，是皆惑于名而忘其义者也。故曰：明主之治，务在审孝悌忠顺之实，而不贵其虚名。父有贤子，君有贤臣，则国治而家安。臣弑其君，子弑其父，非所以为治也。故曰：舜之放其父，非孝也；汤武之伐其君，非忠也。圣人者，必明于此，而后可以为治矣。

且夫上下之利，其异也甚矣。故曰：君以计畜臣，臣以计事君，君臣之交，计也。害身而利国，臣弗为也；害国而利臣，君不为也。臣之情，害身无利；君之情，害国无亲。君臣也者，以计合者也。至夫临难而死节者，此亦人臣之利也。故曰：忠孝者，所以事君事亲之大者也，然其施也，必合乎法而后可也。此忠孝之要旨也。
