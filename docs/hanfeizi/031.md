# 内储说下六微

六微：一曰权借在下，二曰利异外借，三曰托于似类，四曰利害有反，五曰参疑内争，六曰敌国废置。此六者，主之所察也。

权势不可以借人，上失其一，臣以为百。故臣得借则力多，力多则内外为用，内外为用则人主壅。其说在老聃之言失鱼也。是以人主久语，而左右鬻怀刷。其患在胥僮之谏厉公，与州侯之一言，而燕人浴矢也。

君臣之利异，故人臣莫忠，故臣利立而主利灭。是以奸臣者，召敌兵以内除，举外事以眩主，苟成其私利，不顾国患。其说在卫人之妻祷也。故郑伯将伐胡，而先以其女妻胡君以娱其意，而关其思知其计也，因烹之。故曰：反间之计，不可以不察也。其患在怀沙之鬼，与管仲之谋竖刁也。

似类之事，人主之所以失诛，而大臣之所以成私也。是以门者捐水，而夷射诛；济阳自矫，而二人罪。故有患于知，而事有不可知者。其说在燕王之所宫也，与臧孙之怨子南也。故曰：托于似类，则人主之明蔽矣。

事起而有所害，其变也，则为之量其力而避其害。是故利之所在，害之所隐也。其说在赵王养李兑也，与邯郸之战也。故曰：利害有反，则人主之察难矣。

参疑之势，乱之所由生也。故明主慎之。其说在晋献公之惑于骊姬，与郑庄公之宠于叔段也。故曰：参疑内争，则人主之权分矣。

敌之所务，在淫察而就靡。人主不察，则敌废置矣。故曰：敌国废置，则人主之柄移矣。其说在郑昭之因魏也，与周王之数亡也。故曰：明主之于敌也，务在察其情而固其柄，则敌不能废置，而国可守矣。

右经。
