# 大体

古之全大体者：望天地，观江海，因山谷，日月所照，四时所行，云布风动；不以智累心，不以私累己；寄治乱于法术，托是非于赏罚，属轻重于权衡；不逆天理，不伤情性；不吹毛而求小疵，不洗垢而察难知；不引绳之外，不推绳之内；不急法之外，不缓法之内；守成理，因自然；祸福生乎道法，而不出乎爱恶；荣辱之责在乎己，而不在乎人。故至安之世，法如朝露，纯朴不散；心无结怨，口无烦言。故车马不疲弊于远路，旌旗不乱于大泽，万民不失命于寇戎，雄骏不创寿于旗幢；豪杰不著名于图书，不录功于盘盂，记年之牒空虚。故曰：利莫长于简，福莫久于安。

使匠石以千岁之寿操钩，视规矩，举绳墨，而正太山；使贲育带干将而齐万民，虽尽力于巧，极盛于寿，太山不正，民不能齐。故曰：古之牧天下者，不使匠石极巧以败太山之体，不使贲育尽威以伤万民之性。因道全法，君子乐而大奸止。澹然闲静，因天命，持大体。故使人无离法之罪，鱼无失水之祸。如此，故天下不可易也，而四海不可夺也。故曰：古之人，明于全大体，则万物不能役，天下不能伤，然后可以治天下矣。

是故君子不逆天理，不伤情性，因物之性而制之，则不劳而功成。故曰：大匠不斫，大庖不豆，大勇不斗，大兵不寇。惠子言治之至也，曰："治大国者，若烹小鲜。"此言其不可扰也。故曰：明主之道，静则国安，动则国乱，此全大体之要也。
