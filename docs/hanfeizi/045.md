# 诡使

圣人之所以为治道者三：一曰利，二曰威，三曰名。夫利者，所以得民也；威者，所以行令也；名者，上下之所同道也。非此三者，虽有不急矣。今利非民之所利也，威非民之所畏也，名非民之所慕也，则虽有善道，而民不从矣。故曰：明主之治，务在审利、威、名三者之当，则民劝而国治矣。

夫上之所以使下者，刑赏也。今曰：去其刑赏，而使以德化，则下不从。故曰：操杀生之柄，课群臣之能者，人主之要也。威不立，则国乱；赏不施，则臣怠。故曰：明主之治，刑赏并施，而参验以明，则奸臣无所遁其情矣。

今世之所以乱者，在于上之所善者非民之所利也，上之所恶者非民之所害也。民之所利，君不与之；民之所害，君不夺之。故民不从令，而国以乱。故曰：治民之术，在顺其利而制其害，则民莫不劝矣。故曰：利之所在，民归之；害之所存，民去之。此诡使之要旨也。
