# 心度

圣人之治民，度于本，不从其欲，期于利民而已。故其与之刑，非所以恶民，爱之本也。刑胜而民静，赏繁而奸生。故治民者，刑胜，治之首也；赏繁，乱之本也。夫民之性，恶劳而乐佚。佚则荒，荒则不治，不治则乱，而赏刑不行于天下者必塞。故欲举大功，则难矣；而功不可以假人者也。故曰：欲治其法而难变其故者，民乱，不可几矣。

国者，君之车也；势者，君之马也。无术以御之，身虽劳，犹不免乱；有术以御之，身处佚乐之地，又致帝王之功也。夫民之性，喜其乱而不亲其法。故明主之治也，务在明其法禁，正其赏罚，而不徇其民之欲。刑者，所以胜民者也；赏者，所以劝民者也。刑赏当，则民劝而国治。故曰：治民者，本于刑而节于赏，则国富而民治矣。故曰：明主之治国也，务在审度其当，而不诱于民之所欲，则国治而身安矣。此心度之要旨也。
