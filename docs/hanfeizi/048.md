# 八经

一、因情。凡治天下，必因人情。人情者，有好恶，故赏罚可用；赏罚可用，则禁令可立而治道具矣。君执柄以处势，故令行禁止。柄者，杀生之制也；势者，胜众之资也。废置无度，则权渎；赏罚下共，则威分。是以明主不以爱憎不以喜怒决治，更不以好恶枉法，故曰：因情者，因人之好恶而用赏罚也。

二、主道。力不敌众，智不尽物。与其用一人，不如用一国，故智力敌而群物胜。揣中则私劳，不中则在过。下君尽己之能，中君尽人之力，上君尽人之智。是以事至而结智，一听而公会。听不一，则后悖于前；后悖于前，则愚智不分。不公会，则犹豫而不断；不断，则事留。自取一，则毋堕壑之累。故使之讽，讽定而怒。是以言陈之日，必有策籍。结智者事发而验，结能者功见而谋成败。成败有征，赏罚随之，则臣尽其忠矣。

三、起乱。知臣主之异利者王，以为同者劫，与共事者杀。故明主审公私之分，审利害之地，奸乃无所乘。乱之所生者六也：主母、后姬、子姓、弟兄、大臣、显贤。任吏则定，任贤则危。故曰：明主之治，务在慎其所与共治者，则乱无从生矣。

四、立道。参言以知其诚，易视以改其泽，执见以得非常。一用以务近习，重言以惧远使。举往以悉其前，即迩以知其内，疏置以知其外。渐更以离通比，下约以侵其上。相室约其廷臣，廷臣约其官属，兵士约其军吏，遣使约其行介，县令约其辟吏，郎中约其左右，后姬约其宫媛。此之谓条达之道。

五、类柄。言通事泄，则术不行。明主者，其说在于防奸之泄也。夫不可借者，权柄也。借权则奸得乘矣。

六、参言。明主之道，听言不以一人之口断，而参验众端，则言无不信，而事无不实矣。

七、听法。君人者，不任己之私听，而任法之所定，则臣莫敢欺，而国无不治矣。

八、主威。明主之道，务在立威而固柄，不以假人，则国可保而身可安矣。此八经之要旨也。
