# 外储说左上

明主之道，如有若之应密子也。人主之听言也，不以功用为的，则说者多棘刺白马之说；不以仪的为关，则射者皆如羿。人主于说也，皆如燕王学道也，而长说者皆如郑人争年也。是以言有纤察微难而非务也，故李惠宋墨皆画策也；论有迂深闳大非用也，故畏震瞻车状皆鬼魅也；言而拂难坚确非功也，故务卞鲍介墨翟皆坚瓠也。且虞庆诎匠也而屋坏，范且穷工而弓折。是故求其诚者，非归饷也不可。

夫不谋治强之功，而艳乎辩说文丽之声，是却有术之士而任坏屋折弓之人也。故人主之于国事也，皆不达乎工匠之构屋张弓也。然而士穷乎范且虞庆者，为虚辞，其无用而胜；实事，其无易而穷也。人主多无用之辩，而少无易之言，此所以乱也。今世之为范且虞庆者不辍，而人主说之不止，是贵败屋之类，而以玊琬璧待之也。不亦悖乎！

且夫治者，非以辩说之盛也。故曰：明主之治，务在审其当否，而不贵乎辩言。是以有术之士，不慕虚誉，而务其实功。故曰：大巧在所不为，大智在所不虑。故曰：去其辩，去其说，而国治矣。

右经。
