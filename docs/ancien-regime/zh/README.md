# 旧制度与大革命

**作者：** 阿列克西·德·托克维尔（Alexis de Tocqueville）　**原版：** 1856

## 关于本书

托克维尔剖析法国大革命的名作，法文原版。全书追问一个悖论：革命旨在摧毁旧制度，却为何在行政集权、社会结构等层面延续了旧制度？通过档案与制度史的细致考据，揭示革命并非断裂，而是旧制度的完成。

## 核心内容

历史社会学、制度延续性、中央集权、革命

## 在藏书中的位置

与《论美国的民主》互为补充，提供与「西方路径」对照的经典样本，为理解制度变迁中「革命的延续」提供参照。
