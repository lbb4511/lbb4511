# 《平凡的世界》

**作者：** 路遥　**初版：** 1986—1989（三卷，1988 年完稿）

## 关于本书

路遥的长篇巨著，以陕北黄土高原双水村为舞台，围绕孙少安、孙少平兄弟的奋斗历程，全景式再现中国 1975—1985 年城乡社会的大转型。小说刻画普通劳动者在苦难中的坚韧、尊严与理想主义，获第三届茅盾文学奖，是改革开放后影响最广的现实主义长篇之一。

## 核心人物

- **孙少平**：渴望走出土地、以读书改变命运的农村青年，在煤矿与城市的夹缝中坚守精神的高地。
- **孙少安**：扎根土地的实干者，在家庭联产承包与办厂创业中扛起整个家族的重量。
- **田晓霞**：知识与理想之光的化身，与少平跨越阶层的爱情是全书理想主义的巅峰。

## 在藏书中的位置

与《黄河边的中国》相呼应：一为文学叙事，一为田野记录，共同构成理解中国农村与城乡变迁的双重视角。属"精神底色"板块，展示平凡个体在大时代中的生存与抗争。

> 注：路遥（1949—1992）作品仍在版权保护期内，本书仅收录简介，未录全文。
