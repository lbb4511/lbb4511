# 野性的呼唤

**作者：** 杰克·伦敦（Jack London）　**原版：** 1903

## 关于本书

杰克·伦敦的经典动物小说。故事讲述米勒法官宅邸的文明犬巴克被掳走，几经转卖后落入克朗代克淘金荒野，在残酷的拉雪橇生活中逐步唤起体内的野性，最终挣脱人类文明、回归狼群。小说以巴克的重生写就关于本能、自由与自然法则的寓言。

## 核心内容

- 从文明到荒野的回归之路
- 棍棒与獠牙法则下的生存竞争
- 野性血脉的觉醒

## 在藏书中的位置

与《白牙》互为镜像——一头从文明走向荒野，一头从荒野走向文明，共同构成精神底色维度中关于本能与环境关系的文学双壁。本册提供中英对照：下方为第一章中文译文，其余章节见 [English](../README.md)。

## 第一章 走入原始

「古老的游牧渴望在跳动，/撕扯着世俗的锁链；/又一次从冬日的沉睡中苏醒，/唤醒了那野兽的血脉。」

巴克不读报纸，否则他会知道麻烦正在酝酿——不只是冲着他自己，也是冲着所有从普吉特海峡到圣迭戈的潮水线一带的狗：那些肌肉强健、毛发蓬松保暖的狗。因为人们在北极的黑暗中摸索着，发现了一种黄色的金属，而汽船和运输公司正大张旗鼓地宣传这一发现，成千上万的人正涌向北方。这些人需要狗，而他们要的狗是壮实的狗，肌肉有力可供劳作，毛皮厚实可御严寒。

巴克住在圣克拉拉山谷一座阳光明媚的大宅子里。那地方叫米勒法官府邸。宅子退居路后，半隐于树丛之间，透过枝叶可以望见环绕四面的宽敞阴凉的游廊。碎石车道蜿蜒穿过宽阔的草坪，在一棵棵高大杨树的交织枝丫下穿行。宅子后面比前面更显开阔。有宽敞的马厩，十几个马夫和伙计在此当值；一排排爬满藤蔓的仆人小屋；井然有序、望不到头的棚屋；长长的葡萄架；碧绿的牧场、果园和浆果地。还有一口自流井的抽水设备，以及一座大水泥池，米勒法官的孩子们清晨在此沐浴，炎热的午后也在池中纳凉。

而在这广大的领地上，巴克是主人。他出生在这里，在这里度过了他生命中的四年。的确，这里还有别的狗。在这片如此广大的地方，不可能没有别的狗，但它们都不值一提。它们来来去去，住在拥挤的狗舍里，或者像日本哈巴狗图茨、墨西哥无毛狗伊莎贝尔那样，隐居在屋子的深处——它们是些古怪的生物，很少把鼻子探出屋门，也很少踏上地面。另一方面，还有一群狐狸梗犬，至少有二十条，它们冲着从窗户向外张望、被一群手持扫帚拖把的女仆保护着的图茨和伊莎贝尔，发出气势汹汹的狺狺吠叫。

但巴克既不是家犬，也不是狗舍里的狗。整个领地都属于他。他跳进游泳池里嬉水，或是跟随法官的儿子们去打猎；他陪同法官的女儿莫丽和爱丽丝在黄昏或清晨散步；冬夜里，他躺在法官脚边，面对熊熊燃烧的书房炉火；他驮着法官的孙子们，或者让他们在草地上打滚，一路守护着他们的脚步，穿过种种野性冒险，直到马厩院里的喷泉，甚至更远——到放牧围场和浆果地。在梗犬群里，他趾高气扬地踱步；图茨和伊莎贝尔，他则全然不放在眼里，因为他是国王——是米勒法官宅邸里一切爬行、蠕动、飞翔之物（人类也算在内）的国王。

他的父亲埃尔莫是一头巨大的圣伯纳犬，是法官形影不离的伙伴，而巴克也大有希望继承父亲的衣钵。他并不算太大——只有一百四十磅——因为他的母亲谢普是苏格兰牧羊犬。不过，一百四十磅，加上优裕生活和普遍尊敬所带来的威严，足以让他摆出十足的王家风度。自从幼犬时代以来的四年里，他一直过着养尊处优的生活；他对自己颇为自负，甚至有点自命不凡，正如乡村绅士们有时因与世隔绝的处境而生出的那种优越感。但他没有沦为一头被宠坏的家犬，这救了他。狩猎和类似的外出乐趣使他保持了肌肉的结实；而且，同那些酷爱冷水浴的种族一样，对水的喜爱成了他的补剂和健康良药。

1897年秋天，当克朗代克淘金热把世界各地的人拖进冰封的北方时，巴克就是这样一副模样。但巴克不读报纸，他也不知道园丁的一个帮手马努埃尔是个靠不住的家伙。马努埃尔有一个不可救药的恶习：他嗜赌中国彩票。而且，在赌博中，他还有一个致命的弱点——迷信某套"系统"；这注定了他要完蛋。因为要玩一套系统需要钱，而一个园丁帮工的工钱，还不够维持老婆和一大群孩子的开销。

就在马努埃尔背信弃义的那个难忘的夜晚，法官正去参加葡萄干种植者协会的会议，儿子们正忙着组建一个体育俱乐部。没人看见他和巴克穿过果园出去，而巴克还以为那不过是一次散步。除了一个孤零零的人，也没有人看见他们到达那个名叫学院公园的小旗站。这人同马努埃尔交谈，钱在他们之间叮当作响。

"交货之前，你最好把这货物包好。"那陌生人粗声粗气地说，于是马努埃尔把一根粗绳对折，套在巴克脖子上那根项圈底下。

"拧紧它，保准把他勒个够呛。"马努埃尔说，那陌生人咕哝了一声，算是爽快的答应。

巴克带着从容的尊严接受了这根绳子。诚然，这是一种异乎寻常的待遇，但他已经学会信任他认识的人，并认为他们拥有超出他自身的智慧。可是，当绳子的两端被交到那陌生人手里时，他发出了威胁性的低吼。他不过是在表示他的不快，骄傲地相信"表示"就等同于"命令"。但出乎他意料，绳子在他脖子上收紧，令他喘不过气来。他勃然大怒，扑向那人；那人迎上前来，一把扣住他的喉咙，一个利落的扭转把他掀翻在地。然后绳子无情地勒紧，巴克疯狂地挣扎着，舌头耷拉在嘴外，宽阔的胸膛徒劳地喘息。他这辈子从未受过如此卑劣的对待，这辈子也从未如此愤怒过。但他的力气在耗尽，眼神变得呆滞，等到火车被招停、两个人把他扔进行李车厢时，他已经什么都不知道了。

等他恢复知觉，他隐隐感到舌头疼痛，身体在某种运输工具里颠簸着。一声火车过道口时尖利的汽笛长鸣，让他明白自己身在何处。他常跟法官出门旅行，不会认不出坐行李车厢的感觉。他睁开眼睛，眼里涌起一头被绑架的国王的狂怒。那人扑向他的咽喉，但巴克动作更快。他的上下颚咬住了那只手，直到他再次失去了知觉，才松开口。

"可不是，犯癫狂病。"那人说着，把被咬烂的手藏起来，避开被搏斗声引来的行李员。"我正要把他带给老板，去趟旧金山。那边有位顶呱呱的狗医生，说能治他。"

说到那一夜的行程，那人自己在旧金山滨水区一家酒馆后面的小棚屋里，最有说服力。

"我总共才拿到五十块钱，"他嘟囔道，"就算给一千块现钱，我也不愿再来一次。"

他的手裹在一块血淋淋的手帕里，右腿的裤腿从膝盖一直撕裂到脚踝。

"那家伙分了多少？"酒馆老板问道。

"一百。"那人回答。"少一个子儿也不干，我说的。"

"那就是一百五了，"酒馆老板算着账，"他值这个价，不然我就不是人。"

那绑架者解开血迹斑斑的裹布，看着自己皮开肉绽的手。"我要不得狂犬病——"

"那就只能怪你生来就该上绞架。"酒馆老板笑着说。"来，先搭把手，再忙你的去。"他又补了一句。

巴克头昏眼花，喉咙和舌头疼得难以忍受，命都快被掐掉了一半，却还试图面对这些折磨他的人。但他一次次被掀倒、被掐住，直到他们成功地把他脖子上那沉重的黄铜项圈锉下来。然后绳子被解开，他被扔进一个笼子似的板条箱里。

在接下来整个疲惫的夜晚里，他就躺在那里，咀嚼着愤怒和受伤的尊严。他无法理解这一切究竟意味着什么。这些陌生人想拿他干什么？为什么把他关在这个狭窄的箱子里？他不知道为什么，但他感到一种模糊的灾祸临头的压迫感。夜里好几次，当棚屋的门哐当一声打开时，他跳起来，期望看到法官，或者至少是那些孩子。但每一次，从烛光惨淡的油脂蜡烛光里探进来的，都是酒馆老板那张鼓胀的脸。每一次，巴克喉头颤动的那声欢快的吠叫，都扭曲成一声恶狠狠的咆哮。

但酒馆老板并不招惹他，到了早晨，四个人进来，抬起了那个板条箱。巴克断定，又是一群折磨他的人，因为这些人面目狰狞，衣衫褴褛、蓬头垢面；他隔着栅栏向他们咆哮发怒。他们只是笑，还拿棍子捅他，他立刻用牙齿还击，直到他意识到这正是他们想要的。于是他闷闷不乐地趴下，任由箱子被抬上一辆马车。然后，他连同囚禁他的箱子，开始了在无数人手中辗转的旅程。快递处的职员接管了他；他被人用另一辆马车转运；一辆卡车载着他，混在一堆箱子和包裹里，上了渡轮；他又被卡车运下渡轮，送进一个大火车站，最后被安置在了一节快件车厢里。

这节快件车厢被尖叫的火车头拖行了整整两天两夜；这两天两夜里，巴克不吃不喝。愤怒中，他用低吼迎接快件员的第一次接近，他们则以戏弄作为回敬。当他扑向栅栏，浑身颤抖、口吐白沫时，他们嘲笑他、羞辱他。他们像可恶的狗一样呜呜吠叫，学猫叫，扑腾着胳膊学鸡叫。他知道这一切都很愚蠢；但正因为如此，这对他的尊严是更大的冒犯，他的怒火不断膨胀。饿肚子他倒还不太在意，但没有水喝让他痛苦不堪，把他的愤怒煽到了沸点。何况他生性敏感紧张，这种虐待已经使他发起烧来，干渴肿胀的喉咙和舌头又加剧了炎症。

有一件事他感到庆幸：脖子上的绳子解掉了。那曾给了他们不公平的优势；可现在绳子没了，他要让他们见识见识。他们再也别想往他脖子上套绳子。这一点他下了决心。两天两夜他不吃不喝，在这两天两夜的折磨中，他积攒了一大笔怒气，谁要是敢先来招惹他，准没好果子吃。他的眼睛布满血丝，变成了一头暴怒的恶魔。他变化之大，连法官本人也认不出他了；快件员们把他从西雅图的火车上卸下来时，都松了一口气。

四个人小心翼翼地抬着板条箱，从马车上搬进一个围墙很高的小后院。一个壮实的男人，穿着件领口松松垮垮的红毛衣，走出来给车夫在签收簿上签了字。巴克断定，这个人就是下一个折磨他的人，他凶猛地撞向栅栏。那人阴沉地笑了笑，拿来一把斧头和一根棍棒。

"你不是要现在就把他弄出来吧？"车夫问道。

"当然。"那人答道，把斧头劈进板条箱，当作撬棍。

抬箱子进来的四个人立刻四散躲开，爬上墙头找好稳妥的位置，准备看这场好戏。

巴克冲向裂开的木板，把牙咬进去，又冲又扭。斧头落在哪里，他就出现在哪里，狂吠着、咆哮着——他急切地想出去，正如红毛衣那人气定神闲地想把他弄出来。

"来吧，你这红眼睛的恶魔。"当他把板条箱撬开一个足够巴克身子钻出的口子时说道。与此同时，他扔下斧头，把棍棒换到右手。

而巴克的确成了一头红眼睛的恶魔。他收拢身体准备扑击，毛发竖起，嘴边泛着白沫，布满血丝的眼睛里闪着疯狂的光。他直奔那人，带着一百四十磅的怒火，满载着两天两夜积压的激情。在半空中，就在他的上下颚快要咬住那人的时候，他挨了一记重击，身体被挡了下来，牙齿带着令人痛苦的咔嚓声合拢。他翻滚着摔在地上，脊背和肋部着地。他这辈子从没挨过棍子，不明白是怎么回事。他发出一声半是吠叫、更像尖叫的咆哮，再次起身，跃向空中。又是一记重击，他被重重砸在地上。这一次他明白了那是棍棒，但他的疯狂不懂得谨慎。他冲了十几次，而每一次棍棒都击碎他的冲锋，把他打翻在地。

在一次特别凶狠的打击之后，他踉跄着爬起来，头昏眼花，已经无法再冲。他步履蹒跚、软弱无力地晃悠着，血从鼻子、嘴和耳朵里流出来，他那身漂亮的皮毛溅满斑斑血迹和血沫。然后那人走上前来，故意在他鼻子上狠狠击了一棍。与他此前承受的所有痛苦相比，这一下的剧痛都算不了什么。他发出一声几乎如狮子般凶猛的怒吼，再次扑向那人。但那人把棍棒从右手换到左手，冷静地抓住他的下颌，同时向下向后猛扭。巴克在空中画了一个整圆，又画了半个，然后一头一胸砸在地上。

他最后一次冲锋。那人使出了他蓄谋已久的那记狠招，巴克瘫软下去，倒在地上，彻底失去了知觉。

"他不是个驯狗的生手，这话我敢说。"墙上一个人热情地嚷道。

"宁愿天天驯野马，礼拜天还要加倍。"车夫答道，一边爬上马车，赶起了马。

巴克的知觉恢复了，但力气没有。他躺倒在他倒下的地方，从那里望着红毛衣那人。

"'它名叫巴克，'是这么应的名儿。"那人自言自语，引着酒馆老板那封告知箱子货物送达的信。"唔，巴克，我的伙计，"他用亲切的嗓音接着说，"咱们已经小小地较量过一场，最好的办法就是就此打住。你已经明白了你的位置，我也知道我的位置。做条好狗，一切都会顺遂，吉星高照。做条坏狗，我就把你揍得灵魂出窍。明白了吗？"

他说话时，无畏地拍了拍他方才痛打过的脑袋；尽管巴克的毛碰到那只手时不由自主地竖了起来，他还是毫无反抗地忍受了。那人端来水时，他急切地喝起来；后来又从他手里一块接一块地狼吞虎咽了一顿丰盛的生肉。

他被打败了（这他知道）；但他没有被驯服。他从此彻底看清，面对一个手里拿着棍棒的人，他毫无胜算。他学到了这一课，此后一生都铭记不忘。那根棍棒是一个启示。它是他进入原始法则王国的引见，而他欣然接受了这引见。生活的真相露出了更狰狞的面目；而他面对这一面目时虽然毫无畏惧，却唤醒了自己天性中全部的潜在狡黠。随着日子一天天过去，别的狗陆续来了，有的关在板条箱里，有的拴在绳子头上——有的温顺驯服，有的像他当初一样狂吠怒吼；他眼睁睁看着它们一个个落入红毛衣那人的统治之下。一次又一次，当他看着每一次残忍的表演时，教训都被反复敲进巴克心里：一个手持棍棒的人就是立法者，是必须服从的主人，尽管不一定要去讨好。这最后一点巴克从来不屑为之，虽然他确实见过被打败的狗向那人摇尾乞怜、舔他的手。他还见过一条狗，既不肯讨好也不肯服从，最终在争夺支配权的搏斗中被活活打死。

不时有人来，都是些陌生人，他们兴奋地、谄媚地，用各种腔调同红毛衣那人交谈。每当此时，总有金钱在他们之间交割，陌生人便带走一条或几条狗。巴克不知道它们去了哪里，因为它们再也没有回来；但强烈的恐惧攫住了他，每一次没被选中，他都暗自庆幸。

然而，他的时刻最终还是来临了，以一个小小的干瘪男人的形式出现——那人说着蹩脚的英语，夹杂许多巴克听不懂的古怪粗野的感叹。

"该死的！"他看见巴克时喊道。"这可是条顶呱呱的好狗！嗯？多少大洋？"

"三百，还是白送。"红毛衣那人立刻答道。"既然是政府的钱，你总没得抱怨吧，嗯，佩罗？"

佩罗咧嘴笑了。考虑到犬价已被不同寻常的需求抬上了天，对这么一头出色的动物来说，这个价钱并不算冤。加拿大政府不会吃亏，它的急件也不会因此慢上一拍。佩罗懂狗，当他打量巴克时，他知道巴克是千里挑一——"万里挑一，"他在心里评价道。

巴克看见钱在他们之间流转，当那条好脾气的纽芬兰犬柯利和他被那个干瘪的小个子带走时，他并不惊讶。那是他最后一次看到红毛衣那人；当他和柯利在"独角鲸号"的甲板上望着渐渐远去的西雅图时，那也是他最后一次看到温暖的南方。佩罗把柯利和他带到船舱下层，交给一个黑脸大汉，名叫弗朗索瓦。佩罗是法裔加拿大人，皮肤黝黑；而弗朗索瓦是法裔加拿大混血儿，黑上加黑。对巴克来说，他们是新的一类人（他命中注定还会见到更多），他虽然没对他们产生感情，却依然真心实意地敬重他们。他很快发现佩罗和弗朗索瓦是公正的人，执法冷静不偏不倚，又深谙犬性，不会被狗耍弄。

在"独角鲸号"的中层甲板下，巴克和柯利加入了另外两条狗。一条是从斯匹次卑尔根来的大块头雪白狗，是一位捕鲸船长带出来的，后来曾伴随一支地质勘探队深入荒原。他表面上挺友善，骨子里却阴险——一边冲人笑脸相迎，一边琢磨着某种见不得人的勾当，比如第一顿饭就从巴克的食盆里偷食。巴克正要扑上去教训他，弗朗索瓦的鞭梢已在空中呼啸而过，先鞭中了那肇事者；巴克剩下的只有捡回骨头。这是弗朗索瓦的公正，巴克这样认定，这个混血儿在巴克心中的地位开始上升。

另一条狗既不主动接近谁，也不接受谁的接近；他也不曾试图偷窃新来的狗的食物。他是个阴沉抑郁的家伙，毫不含糊地让柯利明白：他只想独处，并且，若有人不让他独处，就要惹出麻烦。人们叫他"戴夫"。他吃饭、睡觉，或是在这间隙打打哈欠，对什么都不感兴趣，哪怕"独角鲸号"穿越夏洛特皇后海峡，像着了魔似的翻滚、颠簸、蹦跳，他也无动于衷。当巴克和柯利激动起来，吓得半疯时，他才像是嫌烦似的抬起头，投来一瞥漠不关心的目光，打个哈欠，又睡了过去。

船身日夜随着螺旋桨不知疲倦的搏动而震颤。尽管日子一天天过去都大同小异，巴克还是明显感到天气在持续变冷。终于，一天清晨，螺旋桨安静下来，"独角鲸号"上弥漫着一种兴奋的气氛。他和别的狗一样感觉到了，知道一场变故就在眼前。弗朗索瓦给他们拴上绳子，带他们上了甲板。第一步踏上那冰冷的地面，巴克的爪子就陷进一种白色的、稀软的东西里，很像烂泥。他打了个响鼻，跳了回来。更多这种白色的东西正从天上落下来。他抖了抖身子，但更多白东西落到他身上。他好奇地嗅了嗅，然后舔了一些到舌头上。这东西像火一样刺痛，眨眼间又消失了。他大惑不解。他又试了一次，结果一样。旁观者哄堂大笑，他觉得羞愧，却不知为何——因为这是他平生第一次见到雪。
