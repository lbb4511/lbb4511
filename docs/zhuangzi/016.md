# 缮性

缮性于俗，俗学以求复其初；滑欲于俗，思以求致其明：谓之蔽蒙之民。

古之治道者，以恬养知。知生而无以知为也，谓之以知养恬。知与恬交相养，而和理出其性。夫德，和也；道，理也。德无不容，仁也；道无不理，义也；义明而物亲，忠也；中纯实而反乎情，乐也；信行容体而顺乎文，礼也。礼乐遍行，则天下乱矣。彼正而蒙己德，德则不冒，冒则物必失其性也。

古之人，在混芒之中，与一世而得澹漠焉。当是时也，阴阳和静，鬼神不扰，四时得节，万物不伤，群生不夭，人虽有知，无所用之，此之谓至一。当是时也，莫之为而常自然。

逮德下衰，及燧人伏戏始为天下，是故顺而不一。德又下衰，及神农黄帝始为天下，是故安而不顺。德又下衰，及唐虞始为天下，兴治化之流，浇淳散朴，离道以善，险德以行，然后去性而从于心。心与心识，知而不足以定天下，然后附之以文，益之以博。文灭质，博溺心，然后民始惑乱，无以反其性情而复其初。

由是观之，世丧道矣，道丧世矣，世与道交相丧也。道之人何由兴乎世，世亦何由兴乎道哉！道无以兴乎世，世无以兴乎道，虽圣人不在山林之中，其德隐矣。隐故不自隐。古之所谓隐士者，非伏其身而弗见也，非闭其言而不出也，非藏其知而不发也，时命大谬也。当时命而大行乎天下，则反一无迹；不当时命而大穷乎天下，则深根宁极而待，此存身之道也。

存身之道，务全乎内。全乎内者，不以利累形，不以身为殉于物。故曰：得之而不加功，失之而不加损，此之谓不淫。不淫于利，则心无所役，而神守其形，形全则德全，德全则道全，道全则神无所动，此之谓全真。全真者，不惑于俗，不忧于变，不为物先，不为物后，虚己游世，以接乎无穷，故能天行而地止，动而若静，静而若动，神明之位定矣。

夫恬淡寂漠，虚无无为，此天地之平而道德之质也。故曰：圣人休焉。休则平易，平易则恬淡，恬淡则忧患不能入，邪气不能袭，故其德全而神不亏。此之谓全德之人。全德之人，其心静也。静则明，明则虚，虚则无，无则不为，不为则得，得则生生而不穷，故能长。故曰：古之人，不惑于知，不累于物，不遗于时，不悖于俗，抱一以处乎其中，此之谓葆光。葆光者，善藏其用者也。

达生之情者，不务生之所无以为；达命之情者，不务知之所无奈何。养形者必先之于物，物有余而形不养者有之矣。有生必先无离形，形不离而生亡者有之矣。生之来不能却，其去不能止。悲夫，世之人以为养形足以存生，而养形果不足以存生，则世奚足为哉！虽不足为而不可不为者，其为不免矣。夫欲免为形者，莫如弃世。弃世则无累，无累则正平，正平则与彼更生，更生则几矣。事奚足遗弃而生奚足遗？弃事则形不劳，遗生则精不亏。夫形全精复，与天为一。天地者，万物之父母也。合则成体，散则成始。形精不亏，是谓能移。精而又精，反以相天。
