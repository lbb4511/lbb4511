# 《血酬定律》

**作者：** 吴思　**初版：** 2003

## 关于本书

"血酬"即流血拼命所得的酬报，体现着生命与生存资源的交换关系。吴思以元规则、潜规则为线索，拆解中国历史中暴力、权力与财富的运作机制：谁掌握暴力，谁就能设定分配规则；人命的价格、官位的行情、皇权的抵押物，皆可计算。

## 核心概念

- **血酬**：以命相搏换来的酬报，是生存博弈的底线价格。
- **元规则**：暴力最强者说了算，是凌驾于一切规则之上的规则。
- **潜规则**：正式制度之外的灰色契约，维系着帝国机器的实际运转。

## 在藏书中的位置

作为"时间纵深"一轴的开端，它用历史上的具体案例为《乡土中国》《置身事内》等当代观察提供制度史背景，也是理解后续"经济基础"各书的一把历史钥匙。
