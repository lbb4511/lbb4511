# 1984

**作者：** 乔治·奥威尔（George Orwell）　**原版：** 1949

## 关于本书

乔治·奥威尔的经典反乌托邦小说。故事设定在「胜利党」统治的极权国度「大洋国」，主人公温斯顿·史密斯在真理部负责改写历史记录。小说以「老大哥」「新话」「思想警察」等概念，描绘了一个权力以监控、谎言与语言改造全面控制个人的世界。

## 核心内容

反乌托邦、极权主义、语言与思想控制、监控社会

## 在藏书中的位置

作为制度文本的反面教材——展示权力如何通过重构语言与记忆来改写规则本身，与《利维坦》以来对主权权力的理论探讨形成对照。
