# 《经济学的思维方式》

**作者：** 保罗·海恩（Paul Heyne）　**初版：** 1973

## 关于本书

一本不堆砌公式的经济学入门，主张"经济学是思考社会协作问题的一种方式"。全书从稀缺性、机会成本、供给与需求等元概念出发，训练读者像经济学家一样权衡取舍、识别激励。

## 核心视角

- **稀缺与选择**：一切经济行为源于欲望与资源的矛盾。
- **机会成本**：任何选择的真实代价是被放弃的次优项。
- **协作秩序**：价格体系是分散知识的协调机制，而非单纯的价值尺度。

## 在藏书中的位置

作为"经济基础"的思维起点，为后续《置身事内》《国富论》等提供方法框架——先掌握经济学的思维方式，再进入具体制度与历史的分析。
