# 《枪炮、病菌与钢铁》

**作者：** 贾雷德·戴蒙德（Jared Diamond）　**初版：** 1997

## 关于本书

追问一个根本问题：为何欧亚大陆的文明在技术、权力与扩张上长期领先其他大陆？戴蒙德的答案是地理与生物条件而非种族优劣：大陆轴线的走向决定了作物与牲畜的传播速度，动植物驯化的多寡催生了人口、文字、病菌与征服力。

## 核心命题

- **地理决定文明节奏**：轴线走向与气候带影响农业传播。
- **动植物驯化的杠杆**：粮食剩余支撑专业化分工与阶级分化。
- **病菌的"帮助"**：传染病意外成为殖民扩张的利器。

## 在藏书中的位置

在"横向比较"中提供跨文明的结构视角，与《论美国的民主》《拥抱战败》共同打破单一文明叙事的框架。
