# 国富论

**作者：** 亚当·斯密（Adam Smith）　**原版：** 1776

## 关于本书

亚当·斯密的开创性著作，被视为现代经济学的奠基。全书以劳动分工为起点，系统阐述价值、价格、分配、货币与市场机制，提出「看不见的手」使自利行为在竞争中导向公共福利。它对自由贸易与市场经济的论证，深刻塑造了此后两百余年的经济思想。

## 核心内容

劳动分工、市场机制、看不见的手、古典政治经济学

## 在藏书中的位置

从分工、交换与市场机制搭建古典经济学的底层框架，是「经济基础」维度中制度经济学之前最重要的源头文本。
