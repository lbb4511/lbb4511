# 《变革中国》

**作者：** 罗纳德·科斯、王宁　**初版：** 2012

## 关于本书

诺贝尔经济学奖得主科斯以制度经济学视角，回顾中国从计划经济向市场经济转型的真实路径：家庭联产承包、乡镇企业、"边缘革命"、双轨制价格与渐进式开放。核心论点是——中国的市场化并非顶层设计的结果，而是被体制边缘的草根实践一步步"逼"出来的。

## 核心命题

- **边缘革命**：体制外的力量率先突破，倒逼政策松动。
- **试验与推广**：中国改革以地方试点代替整体设计。
- **制度变迁的自发性**：市场秩序的生成先于制度的确认。

## 在藏书中的位置

作为"制度变迁"的当代中国案例，与《国家为什么会失败》《大转型》共同追问：制度如何生成、为何变迁。
