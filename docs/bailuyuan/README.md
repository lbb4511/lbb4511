# 《白鹿原》

**作者：** 陈忠实　**初版：** 1993

## 关于本书

陈忠实以陕西关中白鹿原为舞台，写白、鹿两大家族三代人的恩怨纠葛，时间跨度从清末到新中国成立前夕。小说以族长白嘉轩与鹿子霖的对峙为主线，交织宗法礼教、革命洪流与人性欲望，获第四届茅盾文学奖，被誉为"中国当代文学的压卷之作"。

## 核心意象

- **白鹿**：贯穿全书的灵性意象，象征仁义、祥瑞与秩序复归，是白嘉轩一系的道德图腾。
- **祠堂**：宗法权力的物理核心，族规、乡约与礼教的化身。
- **朱先生**：关中最后一代儒生的精神化身，体现传统文人的道德坚守与历史观照。

## 在藏书中的位置

与《金翼》《四世同堂》同为家族命运叙事，从宗法社会视角补全中国基层秩序的历史图景。属"时间纵深"板块。

> 注：陈忠实（1942—2016）作品仍在版权保护期内，本书仅收录简介，未录全文。
