# 《转型中的地方政府》

**作者：** 周黎安　**初版：** 2008

## 关于本书

用"行政发包制"与"政治锦标赛"两个概念，解释中国地方政府官员为何有如此强的经济增长冲动。上级以 GDP 为标尺考核下级的锦标赛机制，将官员晋升与辖区发展绑定，塑造了中国独特的治理结构。

## 核心概念

- **行政发包制**：上级定目标、下级包执行的逐级发包体系。
- **政治锦标赛**：以相对绩效排序决定晋升的零和竞争。
- **县域竞争**：地方竞争构成中国经济活力的制度来源。

## 在藏书中的位置

与《置身事内》互为表里——前者讲官员激励，后者讲财政机制，共同刻画中国经济增长的政府维度。
