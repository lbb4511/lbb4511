# 白牙

**作者：** 杰克·伦敦（Jack London）　**原版：** 1906

## 关于本书

杰克·伦敦的小说，与《野性的呼唤》互为镜像。白牙是荒野中的半狼半犬，在严酷的生存竞争中学会残酷，又在与人类的相处中逐渐被驯化、萌生忠诚与爱。小说以狗的视角呈现环境对天性的塑造，展现从野性到文明的复归之路。

## 核心内容

动物叙事、野性与驯化、环境塑造天性、成长

## 在藏书中的位置

与《野性的呼唤》互为镜像——一头从文明走向荒野，一头从荒野走向文明，共同构成精神底色维度中关于本能与环境关系的文学双壁。
