# 论美国的民主

**作者：** 阿列克西·德·托克维尔（Alexis de Tocqueville）　**原版：** 1835–1840

## 关于本书

托克维尔考察 1830 年代美国民主制度与社会民情的名著。全书分上下两卷：上卷分析美国联邦制的政治运作，下卷探讨民主如何形塑个人主义、习俗与思想生活。它对现代民主的张力——自由与平等的矛盾、多数暴政的危险——的洞见至今仍被反复引用。

## 核心内容

民主制度、社会条件、个人主义、多数暴政

## 在藏书中的位置

与《旧制度与大革命》互为姊妹篇，是理解现代民主制度生成与运作的源头文本，提供与中国路径对照的西方样本。
