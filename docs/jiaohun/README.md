# 《叫魂：1768年中国妖术大恐慌》

**作者：** 孔飞力（Philip A. Kuhn）　**初版：** 1990

## 关于本书

1768 年，一种剪人发辫、盗取灵魂的"叫魂"妖术传闻席卷江南，引发从乡村到朝廷的全链条恐慌。孔飞力以此事件为切口，解剖乾隆朝官僚体制的运作：谣言如何借助信息系统层层上报，皇帝如何利用恐慌整肃官僚，普通百姓如何成为体制的牺牲品。

## 核心命题

- **权力恐慌的传导**：社会恐慌从民间升格为朝廷政治。
- **官僚共谋**：各级官员为自保而虚报、瞒报与夸大。
- **普通人的脆弱**：边缘人群成为"妖术"指控的首选替罪羊。

## 在藏书中的位置

作为"制度实践"的历史原型，它展示了权力自上而下传导时如何扭曲基层治理，与《小镇喧嚣》《苍黄》形成历史与当下的互文。
