# 君主论

**作者：** 尼科洛·马基雅维利（Niccolò Machiavelli）　**原版：** 1532

## 关于本书

马基雅维利写给统治者的政治实操指南。以佛罗伦萨与意大利各邦的现实政治为素材，讨论君主如何获取、维持与巩固权力：何时施恩、何时用武，权术与道德应如何取舍。「目的正当化手段」的现实主义态度，使本书成为政治学「马基雅维利主义」的源头。

## 核心内容

权术、权力获取与维持、现实政治、君主制

## 在藏书中的位置

直面权力获取与维持的现实逻辑，与理想化的制度叙事形成对照，为理解权力运作提供最直接的「正面」文本。
