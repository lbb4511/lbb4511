# 传习录

《传习录》为明代大儒王阳明（王守仁，1472—1529）及其门人弟子所记问答语录与论学书信的汇编，是阳明心学的核心文本。书名取自《论语》"传不习乎"之义，取"传学之所习"之意。全书分上、中、下三卷：上卷为徐爱、陆澄、薛侃所录问答，中卷为答顾东桥、陆原静、罗整庵等论学书札，下卷为黄省曾、钱德洪等所录晚年语要。

《传习录》所阐发的核心宗旨有二：一曰"知行合一"，谓知行之本体本一，知行并进，不可分为两截；二曰"致良知"，谓良知人人本具，致吾心之良知于事事物物，则天理自明。阳明于此提出"心即理"之说，与程朱"格物穷理"之学相抗，开明代心学之宗，其学经王畿、钱德洪等传承，流布天下，蔚为一代学术主潮。
